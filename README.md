# Binance Spot Paper Trading Bot

A Python project for testing Binance Spot trading strategies with real market prices and simulated orders. The paper-trading mode does not place real orders and does not require Binance API keys.

## Planned features

- Read public Spot market prices
- Simulate buy and sell orders
- Track a virtual quote balance and asset holdings
- Record simulated trades and portfolio value
- Add configurable strategy and risk limits
- Keep live trading disabled by default

## Safety

This project is intended for paper trading first. Never commit API keys, secrets, passwords, or `.env` files to GitHub. A future live-trading feature, if added, must be explicitly configured and tested separately.

## Project status

Initial repository setup. The trading code and tests have not been added yet.
